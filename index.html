Automatic lead sources

Add a Google Alert RSS feed, industry RSS feed, tender feed, or a public webpage. The server checks enabled sources on a schedule and adds only posts containing both EV-charging terms and buying/installation intent.

1. Create buyer-intent alerts

Create Google Alerts for phrases such as "EV charging station required", "looking for EV charging partner", "EV charging" tender Tamil Nadu, and "EV charging" RFP Karnataka. Choose RSS delivery and paste each RSS URL under Auto Sources.

2. Add tender / public pages

Add public pages that list EV charging requirements. The generic HTML monitor scans visible links and nearby text. Prefer official feeds/APIs when available and comply with each site's terms of use.

3. Deploy continuously

Deploy this app to a Python/Docker host. While the server is running, it syncs sources every 30 minutes by default. Change SYNC_MINUTES if needed.

4. Qualify before outreach

Auto-discovered leads are signals, not guaranteed opportunities. Open the original source, confirm location/deadline/eligibility, then move the status from New → Contacted → Qualified → Proposal → Won.
